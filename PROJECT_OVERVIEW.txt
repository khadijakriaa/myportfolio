QUICK START
================================================================================

LOCAL DEVELOPMENT:
  1. npm install
  2. npm run dev
  3. Open http://localhost:3000

PRODUCTION BUILD:
  1. npm run build
  2. npm run start
  3. Open http://localhost:3000

DEPLOY (Choose One):
  Option A - Vercel (Recommended):
    • npm install -g vercel
    • vercel --prod

  Option B - Netlify:
    • npm install -g netlify-cli
    • netlify deploy --prod --dir=.next
